# Roadmap

1. **Setup**: pin engine (Unity 6.3), configure project, create the Unity project skeleton.
2. **Prototype A, portals solo**: first-person controller, Q/E portals, see-through rendering, momentum-preserving teleport, one test room. Pass/fail: does it feel good?
3. **Prototype B, arena loop**: weapons with fixed spawns, health, respawn, frag and time limit vs bots.
4. **Design docs**: GDDs for portals, movement, weapons, match rules ([[04 Core Systems]]).
5. **Multiplayer slice**: 2 to 4 players, server-authoritative, one map.
6. **Maps and weapons content**: 3 to 4 maps, full weapon set.
7. **Polish and publish**: audio, UI, menu, build and playtests.

Status: step 1.
