# Controls (draft, PC first)

| Action | Key |
|---|---|
| Left portal (blue) | **Q** |
| Right portal (orange) | **E** |
| Move | WASD |
| Jump | Space |
| Slide / crouch | Left Ctrl / C |
| Fire | LMB |
| Alt fire | RMB |
| Weapon swap | Mouse wheel / 1-8 |

Notes
- Q and E place a portal on the surface under the crosshair (hitscan ray to a portalable surface). Pressing again moves that portal.
- All bindings go through the Unity Input System so they can be remapped and later mapped to mobile/gamepad (see [[05 Tech - Unity]]).
- Open: how to place portals while holding a weapon, see [[09 Open Questions]].
