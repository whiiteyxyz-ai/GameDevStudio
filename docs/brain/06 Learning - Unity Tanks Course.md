# Unity course: Tanks, make a battle game for web and mobile

Course: https://learn.unity.com/course/tanks-make-a-battle-game-for-web-and-mobile?version=6.3 (Unity 6.3, by Unity Technologies). Provided as a CSV by the project owner.

| Tutorial | Time | Transfers to this project |
|---|---|---|
| Scene setup | 30m | Project and scene structure |
| Tank control | 45m | Input, movement, collision, engine audio |
| Camera and lighting | 20m | Camera rig, lighting for map mood |
| Firing shells | 45m | Weapon firing, projectile logic, charge indicator |
| Tank health | 30m | Health UI, death effects |
| Enemy tank variants | 30m | Bots (useful for solo testing) |
| Audio mixing | 30m | Audio Mixer, music and SFX balance |
| Start menu and Game Manager | 1h | Title screen, Game Manager, player selection |
| Bonus features | 1h | Polish |
| Publish for web and mobile | 30m | Mobile controls, publish to Unity Play |

Use it as a Unity-basics warm-up; our game is first-person, so movement and camera will differ. Total about 6 hours.
